## 🌟 产品定位与核心优势

* 🛡️ **绝对隐私保障 (Local-First)**：原始文档、全文切块、SQLite 数据库与向量索引 100% 保存在用户本地，绝不向第三方云端上传私密文档。
* ⚡ **纯离线向量计算**：内置 FastEmbed (`BAAI/bge-small-zh-v1.5`) 模型，毫秒级本地切块嵌入，零 API Token 消耗。
* 🎯 **RRF 混合检索引擎**：融合 ChromaDB 稠密向量与 SQLite 稀疏关键词精确分词，代码函数名（如 `fruits.pop(10)`）与特定数值 100% 准确定位。
* 💎 **原生 macOS 质感**：沉浸式暗黑/护眼黄/学术白三大主题、窗口坐标防抖记忆、macOS 原生菜单栏与全套快捷键。

## 📦 快速下载与安装指引

### 方式一：直接安装官方 DMG 分发包（推荐）
1. 从 `apps/desktop/release/` 目录中找到 **`智阅 AI-1.0.0-arm64.dmg`**；
2. 双击打开 `.dmg` 磁盘映像，将 **「智阅 AI」** 图标拖入右侧的 **`Applications` (应用程序)** 文件夹；
3. 打开 Launchpad 或应用程序文件夹，点击「智阅 AI」即可秒级启动。

> 💡 **macOS 首次打开安全提示排查**：  
> 若系统弹出提示“*无法打开「智阅 AI」，因为无法验证其开发者*”：  
> - 可以在「访达」->「应用程序」中找到智阅 AI，**右键按住 Control 键并点击「打开」**，在弹窗中选择「打开」即可永久信任；  
> - 或在终端执行快速解除隔离命令：  
>   ```bash
>   xattr -cr "/Applications/智阅 AI.app"
>   ```

### 方式二：绿色免安装 ZIP 包
解压 `apps/desktop/release/智阅 AI-1.0.0-arm64-mac.zip`，直接双击运行其中的 `智阅 AI.app`。

## 🚀 六大核心功能使用说明

### 3.1 知识库中枢：双视图与批量管理
* **拖拽导入**：支持将 PDF、DOCX、TXT、Markdown 文件直接拖入应用窗口，系统通过 SHA-256 哈希自动去重入库。
* **双视图切换**：
  - **卡片网格视图**：类似 Apple Books 的拟物渐变书封，展示阅读进度条、文件体积与快捷管理按钮；
  - **列表视图**：清晰展示页数、字符数、入库时间与标签，适合大量文献的集中检索。
* **内联重命名**：双击卡片或列表中的文件标题，即可原地编辑，按 `Enter` 保存，按 `Esc` 放弃。
* **批量多选工具栏**：勾选多份文档后，底部升起毛玻璃悬浮操作栏：
  - **🏷️ 批量打标**：一键为所选文档附加或新增自定义标签；
  - **📥 导出笔记**：一键将所选文档的所有划线摘录与 AI 批注打包合并为 Markdown 知识沉淀文件；
  - **🗑️ 批量删除**：同时安全清除文档、受管文件与 ChromaDB 向量缓存。

### 3.2 深度精读：Apple Books 护眼排版与全键盘流
* **三大护眼主题**：点击顶栏 `aA` 按钮，自由切换「学术纯白」、「羊皮纸护眼黄」与「OLED 极夜深黑」。
* **纯净精读 vs 原版对照**：
  - **精读排版**：过滤乱码杂质，代码片段自动呈现高亮卡片，排版字阶分明；
  - **原版对照**：针对 PDF 原版论文或教案，查看物理高保真排版。
* **沉浸极客键盘流**：
  - 选中文本后，直接敲击数字键 `1`（🟡黄色重点）、`2`（🟢绿色理解）、`3`（🟣紫色思考）、`4`（🔵蓝色疑问），秒级落盘批注；
  - 键盘 `J` / `←`：快速翻至上一页；`K` / `→`：快速翻至下一页；
  - `Esc`：一键关闭所有浮层弹窗。

### 3.3 认知科学四色高亮与 AI 串联解读
智阅 AI 将用户划线划分为四个维度：
- 🟡 **核心重点**：重要定义与核心结论
- 🟢 **认知理解**：逻辑推导与阶段性认知
- 🟣 **个人思考**：读后反思与批注感悟
- 🔵 **疑难困惑**：未解之谜与技术痛点

👉 **一键 AI 串联攻坚解读**：点击笔记面板顶部的 **「🌟 全篇划线 AI 串联解读」**，AI 将分散在全书各章节的四色划线融会贯通，重点攻坚攻克蓝色疑难标记，并输出高质量全景 Markdown 研读报告。

### 3.4 交互式思维脑图画布 (Mindmap Canvas)
* **开启方式**：进入阅读器右侧「思维大纲」标签，切换至「脑图」视图或点击「⛶ 全屏脑图」。
* **智能解析**：自动解析 AI 生成的大纲、文档原生 TOC 目录树或页面标题，提炼横向发散脑图。
* **操控与穿透**：
  - **拖拽平移 & 滚轮缩放**（40% ~ 200% 平滑缩放）；
  - **节点收起/展开**（二级分支默认折叠，视野清爽有序）；
  - **🎯 直达原文**：点击脑图上的任意节点，阅读器即刻跳转到对应物理页码；
  - **📥 导出高清 PNG**：基于 2x Retina Canvas 离线生成高分辨率透明脑图图片，方便插入论文与汇报。

### 3.5 AI 伴读追问、RRF 混合检索与原文溯源微胶囊
* **即时伴读追问**：在右侧「即时追问」面板随时输入提问，AI 实时理解全文展开多轮深度探讨。
* **宏观语境注入**：划词选中文本提问时，系统自动携带所属文档名及当前章节标题，彻底根除代词幻觉。
* **溯源微胶囊 (Citations)**：AI 生成的回答下方会自动附带可点击的胶囊标牌（如 `[ 🧭 P.3 · 任务五 ]`）。
* **呼吸柔光聚焦**：点击胶囊标牌，阅读器瞬间跳转定位，页眉动态闪烁 `📍 溯源已定位`，正文呈现 2.2 秒科技感脉冲柔光，精准指示视线。
* **按文档独立记忆**：切换阅读不同文档，伴读会话自动隔离并持久化，切回原文档完整复原对话。点击「新对话」可一键重置当前文档记录。

### 3.6 格式工坊：本地零数据外发格式转换
* 点击左侧导航栏的 **「格式工坊」**；
* 支持 PDF $\rightarrow$ Markdown/TXT、DOCX $\rightarrow$ Markdown/TXT、TXT $\leftrightarrow$ Markdown；
* 本地纯 Python 流水线解析，零数据外发，毫秒级提取纯净 Markdown，支持一键复制与本地另存。

## ❓ 常见问题与排错指引 (FAQ)

### Q1: 第一次使用需要配置什么？
> **答**：智阅 AI 的文档解析、切块嵌入、全文检索与脑图生成 **100% 离线脱网运行，零配置可用**。  
> 仅当您需要使用「AI 伴读追问」、「全文智能摘要」与「划词翻译解读」时，需点击左下角 **「偏好设置」**，填入您的 **DeepSeek API Key**（或任何兼容 OpenAI 协议的模型密钥），点击测试连通即可。

### Q2: 我的私密文件会被上传到网上吗？
> **答**：**绝不会**。智阅 AI 坚定践行 Local-First 理念：
> - 导入的原始文件存放在本地 `~/Library/Application Support/ZhiyueAI/storage`；
> - 向量数据库与 SQLite 数据库全部保存在本地磁盘；
> - 嵌入模型内置在应用中，切块提取完全离线；
> - 只有在您主动点击 AI 总结或伴读追问时，系统才会仅将命中的少量相关参考段落发送给大模型 API。

### Q3: 为什么清理软件（如 CleanMyMac / 柠檬清理）会检测到两个“智阅 AI”？
> **答**：这是正常现象。
> - 一个是您安装在 `/Applications/智阅 AI.app` 的正式应用程序；
> - 另一个是源码编译构建输出目录 `apps/desktop/release/mac-arm64/` 下的构建产物。二者完全相同，您可以放心保留 `/Applications/智阅 AI.app`，并在清理软件中直接清理掉 release 目录下的重复项。

## 🛠️ 技术架构与源码编译

如果您是开发者或希望自行编译构建，请参考以下指南：

### 技术栈底座
- **桌面端**：Electron 34 + React 18 + TypeScript + Vite + TailwindCSS
- **后端服务**：Python 3.12 + FastAPI + SQLAlchemy 2.0 (WAL 模式) + Pydantic v2
- **向量化与存储**：FastEmbed (`bge-small-zh-v1.5`) + ChromaDB + SQLite 3
- **文档引擎**：PyMuPDF (fitz) + python-docx + mammoth

### 一键构建 DMG 安装包
项目根目录下提供了全自动打包脚本：
```bash
# 赋予执行权限并运行一键生产级打包
./scripts/build.sh
```
执行完毕后，即可在 `apps/desktop/release/` 下获得新鲜出炉的 `智阅 AI-1.0.0-arm64.dmg` 与 `智阅 AI.app`。
